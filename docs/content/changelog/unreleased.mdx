## Breaking changes

- `CLI.complete` gives `Suggestion` objects, the shape an argument's `suggestions` takes, and the `Completion` type is removed. An option's names and a subcommand's aliases are one suggestion, so a prompt can show `-t, --times` together.

  ```ts
  (await CLI.complete(spec, [], "-")).map((c) => c.value); // 7.0
  (await CLI.complete(spec, [], "-")).flatMap((s) => (typeof s.name === "string" ? [s.name] : s.name)); // next
  ```

## Added

- A suggestion can be `incomplete`, like `user@`, so the shell adds no space after it.

## Fixed

- A repeatable option that's missing an option it `dependsOn` reports it once. It was once for each use.
- `options.count()` of an option used without values, like a flag that isn't repeatable, is 1. It was 0.
- An option that requires a separator, like `--mode=`, completes without a space after it in Bash and Fish.
- Every name of a suggestion is offered. Only the first was.
