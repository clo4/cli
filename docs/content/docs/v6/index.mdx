`@clo4/cli` builds command-line tools from plain objects. A command definition describes its arguments, options and subcommands. The library uses that definition to parse input, infer TypeScript types, print help and answer shell completion requests.

An action is the function that runs a command. It receives parsed strings. Your code decides what those strings mean and what work to do.

## Install

```sh
npm install @clo4/cli
```

The package uses ECMAScript modules and has no runtime dependencies. Type inference requires TypeScript 6.0 or later.

## A complete CLI

Save this example as `demo.ts` in a project with `"type": "module"` in `package.json`. Node.js 24 or later can [run this TypeScript directly](https://nodejs.org/api/typescript.html#type-stripping).

```ts
import * as CLI from "@clo4/cli";

const spec = CLI.spec({
  name: "demo",
  description: "A small build tool.",
  options: [CLI.help],
  subcommands: [
    {
      name: "build",
      description: "Build a project.",
      args: {
        name: "input",
        description: "Source directory.",
        isOptional: true,
        default: ".",
        template: "folders",
      },
      options: [
        { name: ["-w", "--watch"], description: "Watch for changes." },
        {
          name: ["-o", "--output"],
          description: "Output directory.",
          args: { name: "dir", default: "dist", template: "folders" },
        },
      ],
      action({ args: [input], options }) {
        console.log(`${input} -> ${options.get("--output")}`);
        if (options.has("--watch")) {
          console.log("Watch mode enabled.");
        }
      },
    },
    CLI.helpCommand,
    CLI.completion,
  ],
});

CLI.run(spec);
```

```console
$ node demo.ts build
. -> dist
$ node demo.ts build src -o public --watch
src -> public
Watch mode enabled.
```

`CLI.spec` gives the action its types and returns the object unchanged. In this action, `input` and `options.get("--output")` are strings because both inputs have defaults. TypeScript rejects an unknown option name such as `options.has("--watc")`.

`CLI.run` parses the command line and calls the selected action. A command without an action prints help, so `node demo.ts` lists the available commands.

## Help and completion

The example includes three built-in objects. `CLI.help` adds `-h` and `--help` to the root and every descendant command. `CLI.helpCommand` adds `demo help build`. `CLI.completion` prints installation scripts for Bash, Zsh, Fish, PowerShell and Nushell.

```console
$ node demo.ts build --help
Build a project.

Usage:
  demo build [flags] [input]

Arguments:
  input  Source directory. (default: .)

Flags:
  -w, --watch         Watch for changes.
  -o, --output <dir>  Output directory. (default: dist)

Global flags:
  -h, --help          Print a help message
```

The `template: "folders"` fields tell completion to suggest directories. They do not require a path to exist. Your action handles that validation.
